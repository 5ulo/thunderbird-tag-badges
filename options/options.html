THUNDERBIRD · TAG BADGES

Tags that stand out.

Your existing message tags as solid color badges.

Display

0 = no count limit. Only whole badges that fit are shown. Remaining tags are summarized as +N; hover to see the full list.

Select a tag and move it. This only changes display order in the add-on. New tags are added at the end.

Appearance

Badge colors come from Thunderbird. Text is automatically black or white for higher contrast.

Diagnostics

Diagnostics are written to the error console. Message subjects and bodies are not logged.
